# ملاحظاتي — مساحتك الخاصة للملاحظات

تطبيق ويب متكامل لإدارة الملاحظات، يعمل **بالكامل في المتصفح** دون أي خادم أو قاعدة بيانات خارجية.
كل مستخدم يسجّل الدخول ببريده الإلكتروني وكلمة مرور، ويصل إلى **ملاحظاته الخاصة فقط** — لا يطّلع على
ملاحظات غيره، ولا يستطيع أحد غيره تعديلها أو حذفها.

> **🔗 تجربة مباشرة:** <https://honorm2647-ai.github.io/mynotes/>
> **📦 المستودع:** <https://github.com/honorm2647-ai/mynotes>

---

## التشغيل

الطريقة الأسرع — افتح `index.html` بالنقر المزدوج. لا يحتاج المشروع إلى أي تثبيت أو بناء.

إن أردت تشغيله عبر خادم محلي (مستحسن، لأن `file://` قد يحدّ من بعض صلاحيات المتصفح):

```bash
python -m http.server 8088
# ثم افتح: http://localhost:8088
```

أو بأي خادم ملفات ثابت آخر (`npx serve`, `php -S`, إلخ).

> **المتطلبات:** متصفح حديث يدعم Web Crypto — Chrome / Edge / Firefox / Safari (إصدار 2021 فما بعد).

## المزايا

### الحسابات والخصوصية
| | |
|---|---|
| تسجيل حساب | بريد إلكتروني + اسم + كلمة مرور (8 أحرف على الأقل) مع مؤشر قوة لكلمة المرور |
| تسجيل الدخول | تجزئة كلمة المرور بـ **PBKDF2-SHA256** (‏210,000 دورة) مع ملح عشوائي لكل مستخدم |
| عزل البيانات | مفتاح تخزين منفصل لكل مستخدم: `mynotes.v1.u.<userId>.notes` |
| تشفير المحتوى | ملاحظات كل مستخدم مشفّرة بـ **AES-GCM-256**، والمفتاح مُشتق من كلمة مروره |
| قفل التطبيق | «قفل» يمسح مفتاح التشفير من الذاكرة فوراً — يطلب كلمة المرور عند العودة |
| تذكّرني | يحفظ الجلسة محلياً لتفادي إعادة إدخال كلمة المرور في كل زيارة |

### إدارة الملاحظات
- إنشاء، تعديل، حذف (سلة محذوفات + استعادة + حذف نهائي)
- تثبيت ⇢ المفضلة ⇢ الأرشيف ⇢ التصنيفات
- ثمانية ألوان للملاحظات، تصنيفات مخصصة، ووسوم (Tags) قابلة للإضافة بـ `Enter`
- بحث فوري في العناوين والمحتوى والوسوم مع تظليل النتائج
- أربعة أنواع ترتيب: الأحدث تعديلاً، الأحدث إنشاءً، حسب العنوان، الأقدم أولاً
- عرض شبكي أو قائمة، مع حدس للكلمات والوسوم
- ملاحظات ملوّنة + بطاقات أنيقة بحركات انتقال ناعمة

### الواجهة
- تصميم عربي **RTL كامل** مبني على الخصائص المنطقية (`inset-inline`, `padding-inline`) لا على left/right
- سمتان: فاتحة وداكنة، تتبعان تفضيل النظام افتراضياً
- متجاوبة بالكامل: شريط جانبي ينزلق على الجوال، وزر إجراء عائم (FAB)
- إشعارات Toast، نوافذ تأكيد، ومؤشرات تحميل
- اختصارات لوحة المفاتيح، وسماتreduced-motion، وتهيئة لRTL/LTR

### البيانات
- تصدير كل الملاحظات إلى ملف JSON، واستيراد مجدد
- مؤشر لاستهلاك مساحة التخزين
- سلة محذوفات مع استعادة

## نموذج البيانات

كل ملاحظة:

```js
{
  id: 'n_9f3a...',        // معرّف فريد
  title: 'خطة الربع الأول',
  body: 'أهداف الفريق ومواعيد التسليم…',
  tags: ['عمل', 'تخطيط'],
  color: '#6366f1',       // لون الملاحظة
  categoryId: 'c_21b…',   // التصنيف (أو null)
  pinned: false,
  favorite: false,
  archived: false,
  trashed: false,         // في سلة المحذوفات
  createdAt: '2026-10-21T…',
  updatedAt: '2026-10-21T…'
}
```

مفاتيح التخزين في `localStorage`:

```
mynotes.v1.users                   سجل المستخدمين (تجزئات، بلا كلمات مرور)
mynotes.v1.u.<userId>.notes        ملاحظات المستخدم — مشفّرة AES-GCM
mynotes.v1.u.<userId>.categories   تصنيفات المستخدم — مشفّرة AES-GCM
mynotes.v1.session                 الجلسة الحالية
mynotes.v1.remember                الجلسة المحفوظة + مفتاح التشفير (اختياري)
mynotes.v1.settings                المظهر وطريقة العرض والترتيب
```

## نموذج الأمان — وما لا يغطيه

**ما هو مطبَّق**

1. **لا تُخزَّن كلمة المرور إطلاقاً.** يُخزَّن ملح عشوائي + تجزئة PBKDF2 فقط.
2. **عزل منطقي كامل.** بيانات كل مستخدم في مفاتيح مستقلة لا يقرأها غيره.
3. **تشفير المحتوى.** ملاحظات المستخدم مشفّرة AES-GCM-256 في التخزين؛ المفتاح مشتق من كلمة مروره
   (PBKDF2، ملح مستقل) ولا يبقى في الذاكرة إلا أثناء الجلسة.
4. **مقارنة آمنة للتوقيت** عند التحقق من التجزئة.
5. **قفل فوري** يمحو المفتاح من الذاكرة.

**القيود الحقيقية — اقرأها بوضوح**

- التخزين في `localStorage` يعني أن البيانات **لا تغادر الجهاز**، وهذا مطلب التصميم. لكنها في متصفح
  المستخدم: أي شخص يملك وصولاً كاملاً لملف المتصفح (أو جهاز آخر غير مقفل) يمكنه قراءة السجل.
- في وضع **«تذكّرني»** يُحفظ مفتاح فك التشفير محلياً لتسهيل الدخول — أي أن من يصل إلى `localStorage`
  يستطيع فك المحتوى. عطّل «تذكّرني» (أو استخدم «قفل التطبيق») للحصول على أقصى حماية.
- التشفير يحمي من **الاطلاع العرضي** على ملاحظات مستخدم آخر، لا من مهاجم يملك وصولاً كاملاً إلى الجهاز.
- لا يوجد خادم، لذا لا يوجد تحقّق مركزي من البريد ولا استرجاع كلمة مرور — **فقدان كلمة المرور يعني فقدان
  الوصول إلى الملاحظات نهائياً**. صدّر ملاحظاتك بانتظام.
