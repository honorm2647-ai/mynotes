# ملاحظاتي — مساحتك الخاصة للملاحظات

تطبيق ويب متكامل لإدارة الملاحظات، يعمل على **قاعدة بيانات Supabase سحابية**.
كل مستخدم يسجّل الدخول ببريده الإلكتروني وكلمة مرور، ويصل إلى **ملاحظاته الخاصة فقط** — لا يطّلع على
ملاحظات غيره، ولا يستطيع أحد غيره تعديلها أو حذفها.

> **🔗 تجربة مباشرة:** <https://honorm2647-ai.github.io/mynotes/>
> **📦 المستودع:** <https://github.com/honorm2647-ai/mynotes>
> **🗄️ المخطط:** [`supabase-schema.sql`](./supabase-schema.sql)

---

## ⚡ التشغيل (3 خطوات)

### 1) أنشئ الجداول في Supabase

افتح **[Supabase Dashboard](https://supabase.com/dashboard) → SQL Editor → New query**، الصق محتوى
[`supabase-schema.sql`](./supabase-schema.sql) كاملاً، ثم اضغط **Run**.

الملchema ينشئ: `profiles` و `categories` و `notes`، مع سياسات **RLS** كاملة، وفهارس، و
`trigger` لإنشاء الملف الشخصي تلقائياً، ودالة `search_notes` للبحث على الخادم.

> الملف آمن للتشغيل أكثر من مرة (يستخدم `if not exists` و `drop policy if exists`).

### 2) اضبط بيانات المشروع

عدّل [`js/config.js`](./js/config.js):

```js
supabase: {
  url: 'https://<project-ref>.supabase.co',
  publishableKey: 'sb_publishable_...'
}
```

### 3) شغّل التطبيق

افتح `index.html` أو انشره على GitHub Pages — لا يحتاج بناءً ولا حزم.

> **الملاحظة:** بما أن المشروع يُخدَم من `https://` عبر GitHub Pages، فسيعمل **بالكامل**.
> إن فتحته مباشرة عبر `file://` فسيعمل المصادقة لكن المتصفح قد يمنع طلبات الشبكة — استخدم خادماً محلياً:
> ```bash
> python -m http.server 8088
> ```

## 🔐 نموذج الأمان

| الطبقة | التفصيل |
|---|---|
| **المصادقة** | Supabase Auth — تجزئة كلمة المرور على **الخادم** (bcrypt)، ولا تُخزَّن أبداً |
| **الجلسات** | JWT مُدار من Supabase، مع تجديد تلقائي (`autoRefreshToken`) |
| **عزل الصفوف** | **RLS** على كل جدول: `auth.uid() = user_id` — مستخدم آخر لا يرى حتى صفاً واحداً |
| **الكتابة** | `with check (auth.uid() = user_id)` — لا يمكن حقن `user_id` يخصّ غيرك |
| **المفتاح المنشور** | `sb_publishable_` آمن للتعريض — هذا هو غرضه، و RLS هو ما يحمي البيانات |
| **المفتاح السري** | `sb_secret_` **لا يُوضع في أي ملف يُخدَم للمتصفح** — يُستخدم في دوال Edge فقط عبر متغيّرات البيئة |
| **منع anon** | `revoke all … from anon` — الزائر غير المسجّل لا يصل إلى أي جدول |

### ⚠️ حدود النموذج (بصراحة)

- **RLS هو خط الدفاع الوحيد**، وهو فعّال ما دام مفعّلاً. راجعه في `Supabase → Table Editor → RLS`
  وتأكّد من بقاء السياسات مفعّلة بعد أي تعديل.
- **تسجيل الدخول بالبريد يتطلّب تأكيد البريد** في الإعداد الافتراضي للمشروع. لتجربة فورية:
  `Authentication → Sign In / Providers → Email` → أطفئ **Confirm email**.
- **حد إرسال رسائل البريد** على الخطط المجانية منخفض، وقد يظهر خطأ «تم تجاوز حد إرسال رسائل البريد»
  عند التسجيل المتكرر. الرسالة تظهر للمستخدم بالعربية مع خيار إعادة الإرسال.
- **لا يوجد استرجاع كلمة مرور** إلا عبر بريدك (Recovery). إن فقدت الوصول إلى البريد، تفقد الوصول للملاحظات —
  **صدّر ملاحظاتك بانتظام**.

## ✨ المزايا

### الحسابات
تسجيل حساب (بريد + اسم + كلمة مرور ≥ 8 أحرف) · مؤشر قوة كلمة المرور · تأكيد البريد مع إعادة إرسال ·
تسجيل خروج · **قفل التطبيق** (يمحو الجلسة محلياً) · تعديل الاسم المعروض · الجلسات تُحفظ تلقائياً.

### إدارة الملاحظات
إنشاء · تعديل · حذف (سلة + استعادة + حذف نهائي) · تثبيت ⇢ تفضيل ⇢ أرشفة ⇢ تصنيفات ·
8 ألوان · وسوم (Tags) · بحث فوري مع تظليل · 4 أنواع ترتيب · عرض شبكي أو قائمة ·
تصدير/استيراد JSON · مزامنة بين كل أجهزتك.

### الواجهة
عربي **RTL كامل** مبني على الخصائص المنطقية · سمتان فاتحة/داكنة تتبعان النظام · متجاوبة بالكامل ·
شريط جانبي ينزلق على الجوال + زر عائم · إشعارات Toast · نوافذ تأكيد · اختصارات لوحة المفاتيح ·
توافق مع `prefers-reduced-motion`.

## 🗃️ نموذج البيانات

**`notes`**

| العمود | النوع | ملاحظات |
|---|---|---|
| `id` | `uuid` | `gen_random_uuid()` |
| `user_id` | `uuid` | `default auth.uid()` → `auth.users(id) on delete cascade` |
| `title` | `text` | حد أقصى 140 حرفاً |
| `body` | `text` | المحتوى |
| `tags` | `text[]` | مصفوفة وسوم |
| `color` | `text` | لون الملاحظة |
| `category_id` | `uuid` | → `categories(id)` **on delete set null** |
| `pinned` / `favorite` / `archived` / `trashed` | `boolean` | |
| `deleted_at` | `timestamptz` | وقت الحذف من سلة المحذوفات |
| `created_at` / `updated_at` | `timestamptz` | `updated_at` يُحدَّث بـ trigger |

**`categories`**: `id`, `user_id`, `name`, `color`, `created_at`
**`profiles`**: `id` (= `auth.uid()`), `display_name`, `theme`, `layout`, `sort_order`, تواريخ

## 🔐 دوال Edge (اختيارية)

حذف الحساب يتطلب صلاحية `service_role`، لذا يُنفَّذ من **الخادم** لا من المتصفح:

```bash
cd supabase/functions/delete-account
supabase secrets set SUPABASE_SERVICE_ROLE_KEY=<your-secret-key>
supabase functions deploy delete-account
```

المفتاح السري يُقرأ من `Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')` — **لا يُكتب في الملف أبداً**،
ولا يُرفع إلى Git (مجلد `supabase/` مستثنى بالكامل في `.gitignore`).
